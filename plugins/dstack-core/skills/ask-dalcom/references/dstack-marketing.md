# DStack Marketing

DStack workflows for marketing and viral growth, from audience research to opportunity scouting. Install it with `claude plugin install dstack-marketing@dstack` in Claude Code or `codex plugin add dstack-marketing@dstack` in Codex; Claude Code invokes its skills as `/dstack-marketing:<slug>`. Read a skill's SKILL.md before you recommend it.

## Routes

- Ground first: `/skill:developer-audience-context` for persona, pains, and trust signals, then `/skill:developer-listening`, `/skill:developer-search`, and `/skill:competitive-intelligence` as the question needs.
- Decide: `/skill:marketing-decision-map` for a broad initiative, `/skill:marketing-assumption-grill` to pressure-test one decision, `/skill:marketing-behavior-audit` before changing copy.
- Brief, produce, and publish: `/skill:content-evidence-brief`, `/skill:offer-page-brief`, `/skill:competitive-content` (user only), `/skill:developer-content` (user only), `/skill:developer-social-drafts` (user only), `/skill:developer-video`, `/skill:developer-release-communication`, `/skill:release-promotion` (user only), `/skill:developer-publishing` (user only), `/skill:developer-community-posting` (user only).
- Programs and growth: `/skill:developer-community`, `/skill:developer-champion-programs` (user only), `/skill:developer-advocacy` (user only), `/skill:developer-lifecycle-messaging` (user only), `/skill:developer-docs-led-growth`, `/skill:developer-utility-growth`, `/skill:developer-discovery-surfaces`, `/skill:open-source-adoption`, `/skill:viral-opportunity-scout` (user only), `/skill:buzzword-hijack`, `/skill:social-sentiment` (user only).
