# DStack Rust

DStack workflows for Rust development: cargo, async, FFI, cross-compilation, debugging, and unsafe review. Install it with `claude plugin install dstack-rust@dstack` in Claude Code or `codex plugin add dstack-rust@dstack` in Codex; Claude Code invokes its skills as `/dstack-rust:<slug>`. Read a skill's SKILL.md before you recommend it.

## Routes

- Writing or reviewing Rust: `/skill:idiomatic-rust`.
- Builds: `/skill:cargo-workflows`, `/skill:rustc-basics`, `/skill:rust-build-times`, `/skill:rust-cross`. The hard parts: `/skill:rust-async-internals`, `/skill:rust-ffi`, `/skill:rust-unsafe`, `/skill:rust-debugging`, `/skill:rust-security`.
