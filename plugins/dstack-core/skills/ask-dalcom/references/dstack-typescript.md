# DStack TypeScript

DStack workflows for modern TypeScript development. Install it with `claude plugin install dstack-typescript@dstack` in Claude Code or `codex plugin add dstack-typescript@dstack` in Codex; Claude Code invokes its skills as `/dstack-typescript:<slug>`. Read a skill's SKILL.md before you recommend it.

## Routes

- Types: `/skill:typescript-best-practices` shapes them, `/skill:typescript-type-hardening` repairs errors and inference.
- Node services: `/skill:nodejs-service-foundations`, then `/skill:nodejs-graceful-shutdown`; crashes, leaks, or event-loop anomalies: `/skill:node-internals-diagnosis` (user only).
