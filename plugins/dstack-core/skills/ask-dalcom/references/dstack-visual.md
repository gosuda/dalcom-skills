# DStack Visual

DStack workflows for diagrams, decks, canvases, and visual explainers. Install it with `claude plugin install dstack-visual@dstack` in Claude Code or `codex plugin add dstack-visual@dstack` in Codex; Claude Code invokes its skills as `/dstack-visual:<slug>`. Read a skill's SKILL.md before you recommend it.

## Routes

- A 3D workflow from an interview: `/skill:compile-3d-workflow`. A pull request review as a canvas: `/skill:pr-review-canvas` (user only). A zoomable pull request map: `/skill:pr-walkthrough` (user only).
